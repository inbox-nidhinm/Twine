# Text

Decisions worth knowing about text, moved out of `CLAUDE.md` on 28 October 2026 so they load only when needed. Keep each entry up to date when its code changes.

- **Text** is set by `TextLayout` in MotionEvaluation, used for measuring (evaluation, the store) and drawing (`MotionRendering/TextImage.swift`), so the box always matches the ink. Lines are placed by hand, one line height each with the glyphs centred in it (Figma's half-leading). A text box's size is always its words' size: `EditorCommand.apply` refits every text layer after every command (`Layer.fittedText`), and `resolve` measures at every frame, moving the anchor by alignment (`TextLayout.anchor`). Text is drawn as an image per text (two during a Counter or Change Text swap, `ShownText`/`TextSwap`), cached by `TextImage.Key`. Its picture is drawn at the size it shows: the renderer's scale times `CoreAnimationRenderer.textZoom` (the stretch of its world transform, its own scale and every group's and frame's, rounded up in half powers of two so a Scale action redraws it a handful of times rather than every frame, never below 1, held to `TextImage.maxSide` pixels), set on the node by `setTextZoom` before each update and for text masks too; until 29 September 2026 it was drawn at its own size and stretched, soft in a frame scaled to 300% (`textInAScaledGroupStaysSharp`). Pictures come out upside down off screen, so `CoreAnimationRenderer.flipsContents` (set by `OffscreenRenderer`) turns them over; `textIsTheRightWayUp` guards it. Text is typed on the canvas (`Canvas/CanvasTextEditing.swift`): `CanvasNSView` conforms to `NSTextInputClient` and keeps a `TextSession` (an `EditableText` from MotionEditing, with its own undo history); `TextGeometry` (MotionEvaluation) gives caret, hit and selection boxes from the same layout that draws the text, transformed into view points for `CanvasOverlay.updateText`. Each keystroke is a step joining the session's others (`EditorController.type`, `ProjectStore.perform(_:joining:)` with the session's `undoKey`; until 29 September 2026 the session held one continuous change open, which swallowed inspector edits made while typing and scrambled undo), so the typing undoes as one step unless something else happens between letters; a joined step records nothing, so each also marks the document changed, or quitting or a crash mid-sentence would find nothing to save, and `EditorWindowController.leave` and `windowWillClose` call `EditorController.finishEditing` first (going Home mid-typing lost the words until 28 September 2026); `responds(to:)` claims Copy, Cut, Paste, Select All, Delete, Undo and Redo only while typing, so otherwise they reach the window controller. `EditorModel.editingText` names the layer being typed into. Words are typed only on the canvas: the inspector's text box went on 28 September 2026 with the Text section's new layout (the user's mock: font; weight and size; an alignment tray of left, centre and right, justify no longer offered though older files keep it, beside Auto or Fixed; letter spacing and line height behind the settings button, `TextSpacingSettings`). A text's colour is its Fill section (`TextFillSection`, `TextContent.color`, with `hidesFill` for the eye, left out of files while it shows) and it may have a Stroke (`TextStrokeSection`, `TextContent.stroke`, solid, centre, inside or outside, corners behind the settings button). `ResolvedText.showsFill` and `.stroke` reach `TextImage`, which strokes the glyphs' outlines (`CTFontCreatePathForGlyph`) clipped inside or outside them, as a shape's stroke is, with the margin grown by the width; `aTextStrokeOutlinesTheLetters` checks pixels. The Stroke action drives a text's stroke (4 October 2026: `LayerState.stroke` from `TextContent.stroke`, offered only on a text that has one, solid colours only in its inspector; a gradient reaching it draws its first stop). Counter and Change Text share the `text` channel; `ActionTracks.shownText` is its walk.
